# Lógica de Programação — IFCE

Repositório da disciplina **Lógica de Programação**, ministrada por Prof. Jonatha Costa no curso de Engenharia de Controle e Automação do Instituto Federal do Ceará.

A disciplina introduz os fundamentos de algoritmos, programação estruturada e implementação em linguagem C.

---

## Objetivo

Disponibilizar materiais didáticos, exemplos, listas, atividades, avaliações e exercícios resolvidos utilizados ao longo da disciplina.

Este repositório serve como apoio para o desenvolvimento de competências em:

- lógica computacional;
- abstração de problemas;
- implementação em linguagem C;
- modularização;
- boas práticas de programação.

---
